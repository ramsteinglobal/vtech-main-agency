# V-Tech — Main Website

A responsive, single-page agency website for the V-Tech brief. This project covers the main agency site only; the four client sites are represented as clearly labeled portfolio concepts.

## Preview

Open `index.html` in a modern browser. The hero uses Three.js from jsDelivr, with custom animated Canvas scenes inside dimensional 3D frames. The portfolio artwork is drawn in code and uses no photographic image assets. Display fonts load from Google Fonts.
